\# Lighty



A lightweight Android app for searching, playing, and downloading media (music, videos, manga, novels) from customizable sources. Built with Kotlin and Jetpack Compose.



Features:

\- Search and manage custom media sources

\- Audio player with lyrics and background playback

\- Video player with HLS (m3u8) and gesture seek support

\- Download manager with batch download, pause, and resume

\- Manga and novel reader

\- Favorites and local file import/export

\- Built-in debug panel for source testing



Modules:

\- `:app` – Android UI and platform integrations

\- `:engine` – Flow engine, downloader, playback interfaces, data stores



Build:



`./gradlew assembleDebug`

\# Lighty



Lighty 是一个轻量的 Android 应用，用于搜索、播放和下载媒体（音乐、视频、漫画、小说）。基于 Kotlin 和 Jetpack Compose 开发。



功能：

\- 搜索和管理自定义媒体源

\- 音乐播放，支持歌词和后台播放

\- 视频播放，支持 HLS（m3u8）和手势快进

\- 下载管理，支持批量下载、暂停、恢复

\- 漫画和小说阅读

\- 收藏以及本地文件导入/导出

\- 内置调试面板，方便测试源



模块结构：

\- `:app` – Android UI 和平台相关集成

\- `:engine` – Flow 引擎、下载器、播放接口、数据存储



构建：



`./gradlew assembleDebug`
